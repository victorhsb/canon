# Canon

Canon helps a developer settle what a project’s terms mean, what its services
promise, how they behave, and which architectural decisions govern the work.
Coding agents can consult those definitions instead of guessing or reopening
settled questions.

Start with [Working with Canon](docs/agent-workflows.md) for the V2 proof of
concept and its record index. The definitions are design drafts, not a
description of features available in the current Go CLI.
