# Working with Canon

**V2 design draft.** Canon has two uses. During ordinary coding, consult
the project’s definitions and apply the decisions that govern the task.
Only the user can start a definition conversation, by explicitly asking to
use Canon. A request to change code is not permission to set a project rule.
