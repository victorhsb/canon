# DM-0013: Proposal

## Status

proposed

## Definition

An answer put to the developer for consideration. Even a complete edit supported by precedent has no authority beyond what the developer has settled. Silence is not approval.

## Avoid

- **standing decision** — a proposal can still be approved, revised, or vetoed

## Relationships

Distinguish from a standing decision (`DM-0014`): use *proposal*
while the answer is under consideration; use *standing decision* when future
work in the stated situation should follow it.
