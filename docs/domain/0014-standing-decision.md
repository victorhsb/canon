# DM-0014: Standing decision

## Status

proposed

## Definition

An understanding settled by the developer that should govern future work in a stated situation. It can be expressed inside a service or design definition; it need not be a separate record.

## Avoid

- **one-off instruction** — “Do this for today’s demo” authorizes the task but sets no rule for future work

## Relationships

Distinguish from a proposal (`DM-0013`): precedent is evidence for what to propose, not authority to extend a rule to a new situation.
